# Content Universe V18 – Prompt Engine

## Tính năng mới

- Kho Prompt riêng.
- Chọn Prompt Style ngay trong AI Studio.
- Prompt mặc định:
  - TikTok Chuẩn Siêu Di Động
  - Viral Tranh Cãi
  - Hài Hước
  - Cảm Xúc
  - Drama Căng
  - Bán Hàng Mềm
  - AI Tự Quyết Định
- Thêm, sửa, xóa, nhân bản Prompt.
- Đặt Prompt mặc định.
- Yêu thích Prompt.
- Theo dõi lượt sử dụng.
- Prompt Editor có System Prompt và User Prompt.
- Hỗ trợ biến:
  - `{{buyer}}`
  - `{{companion}}`
  - `{{location}}`
  - `{{hookSpeaker}}`
  - `{{emotion}}`
  - `{{topic}}`
  - `{{formula}}`
  - `{{length}}`
  - `{{story}}`
- Gemini tự thay biến bằng dữ liệu trong AI Studio.
